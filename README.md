# 鹿港龍山寺・全 3D 立體紙地圖與雙語國際教育示範

## 目錄結構
- `index.html`: 主程式入口
- `config.js`: 12 大景點座標、國小童趣雙語導覽腳本、基礎單字與暖心籤詩庫（專為國小雙語與國際教育設計）（備課修改請改此檔）
- `materials.js`: PBR 材質與宣紙紋理工廠
- `components.js`: 3D 傳統建築構件工廠
- `architecture.js`: 寺廟八大殿宇組裝器
- `engine.js`: 3D 渲染引擎、南管合成音效與英語語音朗讀

## 啟動方式
由於採用 ES6 Modules (`type="module"`)，請使用 VS Code 的 **Live Server** 擴充套件開啟，或直接上傳至 **GitHub Pages** 即可線上瀏覽！
